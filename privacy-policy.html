Privacy Policy

DealCraftModels Publisher

App name: DealCraftModels Publisher

Effective date: October 10, 2026

Last updated: October 10, 2026

1. What this app does

DealCraftModels Publisher is a personal automation tool that creates and manages Pinterest boards and image pins for the DealCraftModels Etsy shop. It publishes organic (non-paid) pins that link to the shop's Etsy product listings.

The app does not run advertisements, does not perform analytics beyond what Pinterest provides natively, and does not interact with any Pinterest account other than the one that explicitly authorizes it.

2. Data we access via Pinterest

The app requests only the minimum OAuth scopes needed for organic pin publishing:

  • boards:read — list the boards owned by the authorized account (to select where to publish).
  • boards:write — create new boards when the account owner requests it.
  • pins:read — read pin details (to verify a pin was created successfully).
  • pins:write — create image pins on boards owned by the authorized account.
  • user_accounts:read — read basic account information (username, account type) to confirm the correct account is connected.

No advertising scopes are requested. No secret-board or secret-pin scopes are requested.

3. How access tokens are stored

When you authorize the app via Pinterest's official OAuth flow, Pinterest issues an access token. This token is stored locally on the account owner's own computer, using the operating system's secure credential storage (macOS Keychain, following the same pattern already used for the owner's other connected accounts).

The token is never transmitted to any third-party server, never embedded in source code, and never shared in chat messages or logs.

4. How to revoke access

You can revoke the app's access at any time:

  • On Pinterest: go to Settings → Security → Apps, find "DealCraftModels Publisher", and click Revoke access.
  • Alternatively, contact the app operator (see Section 7) and request revocation; the locally stored token will be deleted.

After revocation, the app immediately loses all access to your Pinterest account. Previously published pins remain on Pinterest (they are your content); the app cannot delete them after access is revoked — you can delete them manually from your Pinterest account.

5. Data retention and deletion

  • What is stored: the OAuth access token (locally, as described above), board IDs created by the app, and pin IDs created by the app (kept in a local log so the owner can audit what was published).
  • What is not stored: your Pinterest password (never requested, never stored), personal data of other Pinterest users, or analytics data beyond what you can already see in Pinterest's own dashboard.
  • Deletion: to delete all locally stored data, revoke the app's access (Section 4) and request deletion from the app operator. The access token and the local publication log will be permanently deleted.

6. Data sharing

We do not sell, rent, or share your Pinterest data with any third party. The app communicates only with Pinterest's official API (api.pinterest.com) and only for the publishing functions described in Section 1.

7. Contact

For privacy questions, access revocation requests, or data deletion requests regarding this app, contact the operator of the DealCraftModels Etsy shop:

  • Etsy shop: DealCraftModels on Etsy
  • Use the "Contact" button on the shop page to send a message to the shop owner. Please specify that your message concerns privacy or data deletion for the "DealCraftModels Publisher" app.

Note: contacting the shop via Etsy requires an Etsy account (free registration). Etsy messaging is the official and only contact channel for this app; no dedicated email address is provided.

8. Changes to this policy

If this policy changes, the updated version will be published at this same URL with a revised "Last updated" date. Material changes will be communicated to the account owner before they take effect.
